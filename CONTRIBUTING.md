## Contributing

Thank you for your interest in contributing to this project. Suggested ways to contribute:

- File issues for bugs or feature requests.
- Open pull requests with clear descriptions and tests where applicable.
- Keep changes focused and well-documented.

Development workflow:

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature`.
3. Run tests and linters locally.
4. Submit a pull request with a clear description and rationale.

Coding style: follow existing project conventions. Use `black` for formatting where appropriate.
